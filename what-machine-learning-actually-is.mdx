Machine learning sounds like a subject for specialists, so many technicians and engineers leave it alone and tune rules and alarm limits by hand for weeks, when a small model would do the work. The central idea is small. A model is a rule with adjustable numbers. To fit it, a program changes those numbers until the answers of the rule match a set of measured examples. A straight line through measured points is such a model. In this lesson you fit one, see how a fit goes wrong when the rule is too simple or too flexible, and learn to check a model on data it has not seen before you trust it. #MachineLearning #CurveFitting #BiasVariance

## Curve fitting is machine learning

Suppose you measure the electrical power a pump draws at several flows and plot the points. You draw a line through them, so that you can read the power at a flow you did not measure. That is curve fitting. The line is the model, and its slope and its intercept (its height where $x = 0$) are the two adjustable numbers. If you have taken the [Applied Mathematics course](/education/applied-mathematics/), you have done this already.

Machine learning is the same work with three additions:

1. A program searches for the best numbers (optimization).
2. You test the fitted rule on data it has never seen (generalization).
3. You measure how flexible the rule should be (model selection).

### Fitting a line with NumPy

The program below makes 30 points that follow the line $y = 2x + 1$, with random scatter added in the place of measurement noise. You can read $x$ as the flow of the pump and $y$ as its power. Then `np.polyfit` finds the slope and the intercept that fit the points best.

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Generate noisy linear data: y = 2x + 1 + noise
x = np.linspace(0, 10, 30)
y = 2 * x + 1 + np.random.randn(30) * 2

# Fit a line (degree-1 polynomial)
coeffs = np.polyfit(x, y, deg=1)
print(f"Fitted coefficients: slope = {coeffs[0]:.3f}, intercept = {coeffs[1]:.3f}")
print(f"True relationship: slope = 2.000, intercept = 1.000")

# Predict
x_pred = np.linspace(0, 10, 100)
y_pred = np.polyval(coeffs, x_pred)

plt.figure(figsize=(8, 5))
plt.scatter(x, y, color='steelblue', label='Data points')
plt.plot(x_pred, y_pred, color='tomato', linewidth=2, label=f'Fit: y = {coeffs[0]:.2f}x + {coeffs[1]:.2f}')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Linear Fit with np.polyfit')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('linear_fit.png', dpi=100)
plt.show()
print("Plot saved as linear_fit.png")
```

The program prints a slope of 1.796 and an intercept of 1.643. They are close to the true values (2 and 1) and not equal to them, because the noise moved the points. This is a complete machine learning model, the simplest there is: you gave the program examples, it found the two numbers, and the rule now predicts $y$ for any new $x$.

## When fitting goes wrong: overfitting

<InArticleAd />


What happens with a more flexible rule? A polynomial of degree 3 is a curve with 4 adjustable numbers, and one of degree 15 has 16. The more numbers, the more bends the curve can make. The next program uses a harder pattern, one wave of a sine curve with noise, and fits it three times: with degree 1 (a straight line), degree 3 and degree 15.

For each fit it prints the training error as the mean squared error (MSE): take the miss at each point, square it, and average the squares.

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Generate data from a sine curve with noise
x = np.linspace(0, 2 * np.pi, 25)
y = np.sin(x) + np.random.randn(25) * 0.3

# Fit polynomials of different degrees
degrees = [1, 3, 15]
x_smooth = np.linspace(0, 2 * np.pi, 200)

fig, axes = plt.subplots(1, 3, figsize=(15, 4))

for ax, deg in zip(axes, degrees):
    coeffs = np.polyfit(x, y, deg)
    y_fit = np.polyval(coeffs, x_smooth)

    # Training error
    y_train_pred = np.polyval(coeffs, x)
    train_mse = np.mean((y - y_train_pred) ** 2)

    ax.scatter(x, y, color='steelblue', s=40, zorder=5, label='Training data')
    ax.plot(x_smooth, np.sin(x_smooth), 'k--', alpha=0.4, label='True sine')
    ax.plot(x_smooth, y_fit, color='tomato', linewidth=2, label=f'Degree {deg} fit')
    ax.set_title(f'Degree {deg} (Train MSE: {train_mse:.4f})')
    ax.set_ylim(-2, 2)
    ax.legend(fontsize=8)
    ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('overfitting_comparison.png', dpi=100)
plt.show()
print("Plot saved as overfitting_comparison.png")
print()
print("Notice: degree 15 has the LOWEST training error, but it is further")
print("from the true sine than degree 3. It bends toward individual noisy")
print("points and wiggles between them. That is overfitting.")
```

Look at the degree 15 plot. The curve bends toward single training points, so its training error is the lowest of the three (about 0.02, against about 0.08 for degree 3 and 0.33 for the straight line). But the curve swings between the points and near the two ends, and it is further from the true sine than the degree 3 curve. For a new $x$ between the training points, its prediction would be worse than the prediction of the simpler model.

This is **overfitting**: the model has copied the noise in the training data, and not the pattern under the noise.

## The train/test split: the fundamental idea

<InArticleAd />


How do you detect overfitting? Keep some of the data back. The model is fitted to one part, the training set, and never sees the other part, the test set. Then you measure how well it predicts the test set.

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# Generate 50 data points from a sine curve with noise
n_total = 50
x_all = np.sort(np.random.uniform(0, 2 * np.pi, n_total))
y_all = np.sin(x_all) + np.random.randn(n_total) * 0.3

# Split: 35 points chosen at random for training, the other 15 for testing.
# The split must be random. If you took the first 35 sorted points, the test
# points would all lie to the right of the training range, and the test
# would measure extrapolation instead of generalization.
n_train = 35
indices = np.random.permutation(n_total)
train_idx, test_idx = indices[:n_train], indices[n_train:]
x_train, y_train = x_all[train_idx], y_all[train_idx]
x_test, y_test = x_all[test_idx], y_all[test_idx]

print(f"Training samples: {len(x_train)}")
print(f"Test samples:     {len(x_test)}")
print()

# Fit polynomials and measure train AND test error
max_degree = 15
train_errors = []
test_errors = []

for deg in range(1, max_degree + 1):
    coeffs = np.polyfit(x_train, y_train, deg)

    y_train_pred = np.polyval(coeffs, x_train)
    y_test_pred = np.polyval(coeffs, x_test)

    train_mse = np.mean((y_train - y_train_pred) ** 2)
    test_mse = np.mean((y_test - y_test_pred) ** 2)

    train_errors.append(train_mse)
    test_errors.append(test_mse)

# Print key results
print(f"{'Degree':<8} {'Train MSE':<12} {'Test MSE':<12}")
print("-" * 32)
for deg in range(1, max_degree + 1):
    marker = " <-- best test" if deg == np.argmin(test_errors) + 1 else ""
    print(f"{deg:<8} {train_errors[deg-1]:<12.4f} {test_errors[deg-1]:<12.4f}{marker}")

# Plot train vs test error
plt.figure(figsize=(8, 5))
plt.plot(range(1, max_degree + 1), train_errors, 'o-', color='steelblue', label='Training error')
plt.plot(range(1, max_degree + 1), test_errors, 's-', color='tomato', label='Test error')
plt.xlabel('Polynomial degree (model complexity)')
plt.ylabel('Mean Squared Error')
plt.title('Train vs Test Error: The Overfitting Curve')
plt.legend()
plt.grid(True, alpha=0.3)
plt.yscale('log')
plt.tight_layout()
plt.savefig('train_test_error.png', dpi=100)
plt.show()
print("\nPlot saved as train_test_error.png")
```

The program prints both errors for every degree from 1 to 15. As the degree rises:

- The **training error** always falls. More flexibility gives a closer fit to the training points.
- The **test error** falls at first and then rises, when the curve starts to follow the noise. In this run it is lowest at degree 5 (about 0.06) and about nine times larger at degree 15 (about 0.55). It does not change smoothly, because 15 test points give only a rough estimate.

The best model is the one with the lowest test error, not the one with the lowest training error.

## The bias-variance tradeoff

<InArticleAd />


This pattern has a name: the **bias-variance tradeoff**. The two words name the two ways in which a model can be wrong on new data.

```text
  error on new data
    │ \                          /
    │  \                        /
    │   \                      /
    │    \                    /
    │     \                  /
    │      \________________/
    │
    └────────────────────────────────►
      simple                  flexible
            flexibility of the model

    too simple            too flexible
    (underfitting)        (overfitting)
```

**Bias** is the error of a rule that is too simple for the pattern. A straight line fitted to a sine wave has high bias: however much data you give it, a line cannot follow the curve. It underfits.

**Variance** is the error of a rule that changes too much with the data it happened to receive. A degree 15 polynomial changes its shape when you add or remove one training point. It overfits.

The aim is the lowest part of the curve: enough flexibility to follow the real pattern, and not so much that the model follows the noise.

<Card title="Connect to Applied Math" icon="star">
If you studied interpolation in the Applied Mathematics course, you saw a polynomial of high degree swing widely between its points (Runge's phenomenon). Overfitting is the same effect.
</Card>

## Types of machine learning

<InArticleAd />


Curve fitting is one kind of machine learning. There are three kinds, and they differ in what the model is told during training.

### Supervised learning

You have examples for which the right answer is known: for this input, the correct output is that. The model learns the rule that connects them. Each input is called a feature, and the known answer is called a label.

| Input (features) | Output (label) |
|---|---|
| Flow and pressure of a pump | Power in kW |
| Vibration and temperature of a bearing | Healthy or failing |
| Time since the door of a cold room opened | Air temperature in °C |

- **Regression**: the output is a number (a power, a temperature).
- **Classification**: the output is a category (healthy or failing, good or defective).

Most of this course is about supervised learning, because it is the kind you can use soonest in engineering work.

### Unsupervised learning

You have data and no labels. The model looks for structure without being told the answers.

- **Clustering**: put similar data points into groups.
- **Dimensionality reduction**: describe data that has many measurements per point with only a few numbers.
- **Anomaly detection**: find the data points that do not fit the normal pattern.

### Reinforcement learning

A program acts and receives a reward or a penalty for each action. Over many trials it learns which actions bring the most reward. Robotics uses it. This course does not cover it.

## Complete example: the overfitting lab

<InArticleAd />


This program joins the parts of the lesson. It makes a noisy sine data set, splits it into a training set and a test set, fits polynomials of rising degree, and produces a table and two plots: the fits and the error curves.

```python
import numpy as np
import matplotlib.pyplot as plt

np.random.seed(42)

# ── Generate Data ──
n_total = 60
x_all = np.sort(np.random.uniform(0, 2 * np.pi, n_total))
y_true = np.sin(x_all)
y_noisy = y_true + np.random.randn(n_total) * 0.3

# ── Train/Test Split (70/30) ──
n_train = int(0.7 * n_total)
indices = np.random.permutation(n_total)
train_idx = indices[:n_train]
test_idx = indices[n_train:]

x_train = x_all[train_idx]
y_train = y_noisy[train_idx]
x_test = x_all[test_idx]
y_test = y_noisy[test_idx]

print(f"Total samples:    {n_total}")
print(f"Training samples: {len(x_train)}")
print(f"Test samples:     {len(x_test)}")
print()

# ── Fit Polynomials of Increasing Degree ──
degrees = list(range(1, 16))
train_mse_list = []
test_mse_list = []
x_smooth = np.linspace(0, 2 * np.pi, 300)

for deg in degrees:
    coeffs = np.polyfit(x_train, y_train, deg)
    pred_train = np.polyval(coeffs, x_train)
    pred_test = np.polyval(coeffs, x_test)
    train_mse = np.mean((y_train - pred_train) ** 2)
    test_mse = np.mean((y_test - pred_test) ** 2)
    train_mse_list.append(train_mse)
    test_mse_list.append(test_mse)

# ── Print Summary Table ──
best_deg = degrees[np.argmin(test_mse_list)]
print(f"{'Degree':<8} {'Train MSE':<14} {'Test MSE':<14} {'Status'}")
print("=" * 50)
for i, deg in enumerate(degrees):
    if deg < best_deg:
        status = "underfitting"
    elif deg == best_deg:
        status = "BEST"
    elif test_mse_list[i] > test_mse_list[i - 1]:
        status = "overfitting"
    else:
        status = ""
    print(f"{deg:<8} {train_mse_list[i]:<14.6f} {test_mse_list[i]:<14.6f} {status}")

print(f"\nBest polynomial degree: {best_deg}")
print(f"Best test MSE: {test_mse_list[best_deg - 1]:.6f}")

# ── Plot 1: Three Example Fits ──
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
example_degrees = [1, best_deg, 15]

for ax, deg in zip(axes, example_degrees):
    coeffs = np.polyfit(x_train, y_train, deg)
    y_smooth = np.polyval(coeffs, x_smooth)
    pred_test = np.polyval(coeffs, x_test)
    test_mse = np.mean((y_test - pred_test) ** 2)

    ax.scatter(x_train, y_train, color='steelblue', s=25, alpha=0.7, label='Train')
    ax.scatter(x_test, y_test, color='orange', s=25, alpha=0.7, label='Test')
    ax.plot(x_smooth, np.sin(x_smooth), 'k--', alpha=0.3, label='True sine')
    ax.plot(x_smooth, y_smooth, color='tomato', linewidth=2, label=f'Degree {deg}')
    ax.set_title(f'Degree {deg} (Test MSE: {test_mse:.4f})')
    ax.set_ylim(-2.5, 2.5)
    ax.legend(fontsize=7)
    ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('overfitting_lab_fits.png', dpi=100)
plt.show()

# ── Plot 2: Error vs Complexity ──
plt.figure(figsize=(8, 5))
plt.plot(degrees, train_mse_list, 'o-', color='steelblue', label='Training MSE')
plt.plot(degrees, test_mse_list, 's-', color='tomato', label='Test MSE')
plt.axvline(x=best_deg, color='green', linestyle=':', alpha=0.7, label=f'Best degree = {best_deg}')
plt.xlabel('Polynomial Degree (Model Complexity)')
plt.ylabel('Mean Squared Error')
plt.title('Bias-Variance Tradeoff in Action')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('overfitting_lab_error_curve.png', dpi=100)
plt.show()

print("\nPlots saved: overfitting_lab_fits.png, overfitting_lab_error_curve.png")
```

Run the program and compare the three fits. In the table, the training error falls at every degree. The test error is lowest at degree 4 in this run and then climbs. When you see that, stop adding flexibility.

## Key takeaways

<InArticleAd />


<Steps>
1. **Machine learning is curve fitting, extended.** A model is a rule with adjustable numbers, and fitting sets those numbers from data. `np.polyfit` is a machine learning algorithm.

2. **Always measure on unseen data.** The training error shows how closely the model follows the data it was given. Judge a model by its test error.

3. **Underfitting means the model is too simple.** Give it more flexibility or more useful inputs.

4. **Overfitting means the model is too flexible.** It follows the noise as well as the pattern. Reduce its flexibility, collect more data, or add regularization (covered later in the course).

5. **Every choice of model trades bias against variance.** Choose by the lowest test error.
</Steps>
