Two level switches on a tank should always agree, and an alarm should sound when exactly one of them is on. That rule is easy to say, and no straight-line model can learn it, whatever weights you give it. A neural network can, because it arranges simple units in layers, and each unit bends its result before it passes it on. The price is that more happens out of sight: one call to `model.fit()` hides the gradients and the choice of starting weights. In this lesson you build a neural network with NumPy alone, follow every number through it, and train it on exactly this problem. #NeuralNetworks #Backpropagation #NumPy

## A single neuron

A neural network is made of one building block, the neuron. A neuron multiplies each of its inputs by a weight, adds a constant called the bias, and passes the sum through an **activation function**. A neuron with a sigmoid is logistic regression under another name.

In the drawing, $x_1$ and $x_2$ are the inputs (for example the vibration and the temperature of a bearing), $w_1$ and $w_2$ are the weights, $b$ is the bias, $z$ is the weighted sum, and $f$ is the activation function.

```text
  inputs    weights     weighted sum + bias       activation
  x1 ─── w1 ──┐
              ├──► z = w1*x1 + w2*x2 + b ──► a = f(z)
  x2 ─── w2 ──┘
```

<Card title="Why nonlinearity matters" icon="star">
If every neuron only formed its weighted sum, 100 layers would still calculate one weighted sum of the inputs, and a single layer could replace them. The activation function is **nonlinear**: its graph is not a straight line. That bend lets a network learn curved boundaries and thresholds.
</Card>

```python
import numpy as np

np.random.seed(42)

# A single neuron
def single_neuron(x, w, b):
    """Weighted sum + bias, then sigmoid activation."""
    z = np.dot(x, w) + b
    a = 1 / (1 + np.exp(-z))  # sigmoid
    return a

# Two inputs
x = np.array([0.5, 0.8])
w = np.array([0.3, -0.1])
b = 0.2

output = single_neuron(x, w, b)
print(f"Inputs:     {x}")
print(f"Weights:    {w}")
print(f"Bias:       {b}")
print(f"Weighted sum: {np.dot(x, w) + b:.4f}")
print(f"After sigmoid: {output:.4f}")
```

**Expected output:**

```text
Inputs:     [0.5 0.8]
Weights:    [ 0.3 -0.1]
Bias:       0.2
Weighted sum: 0.2700
After sigmoid: 0.5671
```

The sigmoid pressed the sum 0.27 into 0.5671 (its output is always between 0 and 1). That is everything one neuron calculates.

## Activation functions

<InArticleAd />


Two activation functions cover most practical cases. The program also defines the derivative of each one, which is its slope at a given point, because training needs it later.

```python
import numpy as np

np.random.seed(42)

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    """Derivative of sigmoid, given the output a = sigmoid(z)."""
    return a * (1 - a)

def relu(z):
    return np.maximum(0, z)

def relu_derivative(z):
    return (z > 0).astype(float)

# Compare them
z_values = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])

print("z values:       ", z_values)
print("Sigmoid:        ", np.round(sigmoid(z_values), 4))
print("Sigmoid deriv:  ", np.round(sigmoid_derivative(sigmoid(z_values)), 4))
print("ReLU:           ", relu(z_values))
print("ReLU deriv:     ", relu_derivative(z_values))
```

**Expected output:**

```text
z values:        [-2. -1.  0.  1.  2.]
Sigmoid:         [0.1192 0.2689 0.5    0.7311 0.8808]
Sigmoid deriv:   [0.105  0.1966 0.25   0.1966 0.105 ]
ReLU:            [0. 0. 0. 1. 2.]
ReLU deriv:      [0. 0. 0. 1. 1.]
```

**Sigmoid** presses any value into the range from 0 to 1. Use it in an output layer when you want a probability. **ReLU** (rectified linear unit) passes a positive value unchanged and turns a negative value into 0.

<Card title="Why ReLU replaced sigmoid in hidden layers" icon="star">
Look at the row of sigmoid derivatives above. The largest value is 0.25, at $z = 0$. During training, the gradient is passed back from layer to layer, and at each sigmoid layer it is multiplied by this derivative. In a network with 10 sigmoid layers, the gradient that reaches the first layer can be scaled by $(0.25)^{10}$, about one millionth. The early layers almost stop learning. This is the **vanishing gradient problem**.

The derivative of ReLU is 1 for any positive input and 0 otherwise, so it does not shrink the gradient on its way back. Use ReLU in hidden layers, and keep the sigmoid for an output layer that must give a probability.
</Card>

## The XOR problem

<InArticleAd />


XOR ("exclusive or") is the classic test. The output is 1 when exactly one of the two inputs is 1, and 0 otherwise. It is the rule of the two level switches: alarm when they disagree. A model with a single layer cannot solve it, because the two classes are not **linearly separable**: no single straight line has the 1 answers on one side and the 0 answers on the other. A network with two layers can.

```text
  XOR Truth Table          Why Linear Models Fail
  ────────────────         ──────────────────────
  x1  x2  │  y            x2
   0   0  │  0             1 ──── ● (0,1)=1    ○ (1,1)=0
   0   1  │  1             │
   1   0  │  1             │  No single straight line
   1   1  │  0             │  separates ● from ○
                            0 ──── ○ (0,0)=0    ● (1,0)=1
                                   0            1   x1
```

### A note on weight initialization

The program below starts from small random weights, with a scale chosen by hand. That is good enough for two layers. With many layers it fails: the signals grow or die out on their way through. Libraries therefore set the size of the starting weights from the number of connections of each layer: **Xavier (Glorot) initialization** for tanh and sigmoid layers, and **He (Kaiming) initialization** for ReLU layers.

### Building a 2-layer network

The network has 2 inputs, a hidden layer of 4 neurons with ReLU, and 1 output neuron with a sigmoid. A layer is hidden when its values are neither inputs nor outputs.

```text
  input layer    hidden layer         output layer
  (2 values)     (4 neurons, ReLU)    (1 neuron, sigmoid)

  x1 ────┬──── h1 ────┐
         ├──── h2 ────┤
         ├──── h3 ────├──── y_pred
         └──── h4 ────┘
  x2 ────┘
```

The program calculates all four XOR cases at once, so the data and the weights are tables of numbers (matrices). A shape of (4, 2) means 4 rows and 2 columns.

| Name | Shape | Contents |
|---|---|---|
| `X` | (4, 2) | 4 samples with 2 inputs each |
| `W1` | (2, 4) | weights from the 2 inputs to the 4 hidden neurons |
| `b1` | (1, 4) | one bias for each hidden neuron |
| `W2` | (4, 1) | weights from the 4 hidden neurons to the output |
| `b2` | (1, 1) | one bias for the output |

The loop is gradient descent: a forward pass calculates the predictions, a backward pass calculates the gradient for every weight (**backpropagation**, explained after the program), and the update follows.

```python
import numpy as np

np.random.seed(42)

# Activation functions
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(a):
    return a * (1 - a)

def relu(z):
    return np.maximum(0, z)

def relu_derivative(z):
    return (z > 0).astype(float)

# XOR data
X = np.array([[0, 0],
              [0, 1],
              [1, 0],
              [1, 1]])
y = np.array([[0], [1], [1], [0]])

# Initialize weights (random values)
W1 = np.random.randn(2, 4) * 1.0   # input to hidden
b1 = np.zeros((1, 4))
W2 = np.random.randn(4, 1) * 1.0   # hidden to output
b2 = np.zeros((1, 1))

learning_rate = 0.5
epochs = 10000

print("Initial weights W1:\n", np.round(W1, 4))
print("Initial weights W2:\n", np.round(W2, 4))

losses = []

for epoch in range(epochs):
    # Forward pass
    z1 = X @ W1 + b1          # (4, 4)
    a1 = relu(z1)             # hidden activations
    z2 = a1 @ W2 + b2         # (4, 1)
    a2 = sigmoid(z2)          # output prediction

    # Loss (MSE)
    loss = np.mean((y - a2) ** 2)
    losses.append(loss)

    # Backpropagation
    # Output layer gradients
    d_loss_a2 = -2 * (y - a2) / len(y)         # dL/da2
    d_a2_z2 = sigmoid_derivative(a2)            # da2/dz2
    delta2 = d_loss_a2 * d_a2_z2               # (4, 1)

    dW2 = a1.T @ delta2                         # (4, 1)
    db2 = np.sum(delta2, axis=0, keepdims=True)

    # Hidden layer gradients
    delta1 = (delta2 @ W2.T) * relu_derivative(z1)  # (4, 4)
    dW1 = X.T @ delta1                               # (2, 4)
    db1 = np.sum(delta1, axis=0, keepdims=True)

    # Update weights
    W1 -= learning_rate * dW1
    b1 -= learning_rate * db1
    W2 -= learning_rate * dW2
    b2 -= learning_rate * db2

    if epoch % 2000 == 0:
        print(f"Epoch {epoch:5d} | Loss: {loss:.6f}")

print(f"Epoch {epochs:5d} | Loss: {losses[-1]:.6f}")
print("\nFinal predictions:")
for i in range(len(X)):
    print(f"  Input: {X[i]} -> Predicted: {a2[i][0]:.4f} | Target: {y[i][0]}")

print("\nFinal weights W1:\n", np.round(W1, 4))
print("Final weights W2:\n", np.round(W2, 4))
```

```text

 [[ 0.4967 -0.1383  0.6477  1.523 ]
 [-0.2342 -0.2341  1.5792  0.7674]]
Initial weights W2:
 [[-0.4695]
 [ 0.5426]
 [-0.4634]
 [-0.4657]]
Epoch     0 | Loss: 0.355412
Epoch  2000 | Loss: 0.000854
Epoch  4000 | Loss: 0.000352
Epoch  6000 | Loss: 0.000217
Epoch  8000 | Loss: 0.000155

Final predictions:
  Input: [0 0] -> Predicted: 0.0176 | Target: 0
  Input: [0 1] -> Predicted: 0.9921 | Target: 1
  Input: [1 0] -> Predicted: 0.9921 | Target: 1
  Input: [1 1] -> Predicted: 0.0066 | Target: 0
```

The program also prints the final weights. A network this small does not learn XOR from every starting point. With other seeds (3, 4 or 9, for example), or with the same seed and half the weight scale, some ReLU units start with zero output for every input, receive no gradient, and the loss stays near 0.125, 0.167 or 0.25. If that happens, change the seed or use more hidden neurons.

The network has learned XOR: its four outputs are within 0.02 of the targets. A straight-line model cannot get all four cases right, whatever its weights.

## Understanding backpropagation

<InArticleAd />


Backpropagation answers one question for every weight: if this weight rises a little, how does the loss change? It starts from the error at the output and works backwards, layer by layer, and gives each weight its share of the error. In calculus this is the chain rule.

<Steps>

1. **Forward pass**: calculate the predictions, layer by layer.

2. **Loss**: measure how far the predictions are from the targets (the MSE here).

3. **Gradient of the output layer**: find how the loss changes with each output weight, from the derivative of the MSE and the derivative of the sigmoid.

4. **Gradient of the hidden layer**: pass the error back through the output weights and multiply by the derivative of ReLU. Each hidden neuron then has its share of the error.

5. **Update**: subtract the learning rate times the gradient from every weight, and repeat.

</Steps>

```text
  forward:   X ──► z1 ──► a1 ──► z2 ──► a2 ──► loss
                   W1     ReLU   W2     sigmoid  MSE

  backward:  dW1 ◄── delta1 ◄── dW2 ◄── delta2 ◄── loss
```

In the program, `delta2` is the error at the output and `delta1` is the share passed back to the hidden layer. `dW2` and `dW1` are the gradients for the two sets of weights.

## Classifying sensor readings (3 classes)

<InArticleAd />


Now a more practical problem. From the temperature and the vibration of a machine, decide if a reading is normal (0), warning (1) or critical (2). Three things are new:

- **One-hot labels.** Each label is three numbers with a single 1: normal is (1, 0, 0), warning is (0, 1, 0), critical is (0, 0, 1).
- **Softmax.** The output layer turns its three raw scores into three probabilities that add to 1. The highest is the answer.
- **Cross-entropy loss.** The log loss of logistic regression, extended to three classes.

```python
import numpy as np

np.random.seed(42)

# Generate synthetic sensor data
n_samples = 300

# Normal: temp 20-40, vibration 0.5-2.0
temp_normal = np.random.uniform(20, 40, n_samples // 3)
vib_normal = np.random.uniform(0.5, 2.0, n_samples // 3)

# Warning: temp 35-55, vibration 1.5-4.0
temp_warning = np.random.uniform(35, 55, n_samples // 3)
vib_warning = np.random.uniform(1.5, 4.0, n_samples // 3)

# Critical: temp 50-80, vibration 3.5-7.0
temp_critical = np.random.uniform(50, 80, n_samples // 3)
vib_critical = np.random.uniform(3.5, 7.0, n_samples // 3)

X = np.vstack([
    np.column_stack([temp_normal, vib_normal]),
    np.column_stack([temp_warning, vib_warning]),
    np.column_stack([temp_critical, vib_critical]),
])

# One-hot encode labels
y = np.zeros((n_samples, 3))
y[:100, 0] = 1   # normal
y[100:200, 1] = 1  # warning
y[200:, 2] = 1   # critical

# Normalize inputs
X_mean = X.mean(axis=0)
X_std = X.std(axis=0)
X_norm = (X - X_mean) / X_std

# Shuffle
indices = np.random.permutation(n_samples)
X_norm = X_norm[indices]
y = y[indices]

# Split: 80% train, 20% test
split = int(0.8 * n_samples)
X_train, X_test = X_norm[:split], X_norm[split:]
y_train, y_test = y[:split], y[split:]

def softmax(z):
    exp_z = np.exp(z - np.max(z, axis=1, keepdims=True))
    return exp_z / exp_z.sum(axis=1, keepdims=True)

def relu(z):
    return np.maximum(0, z)

def relu_derivative(z):
    return (z > 0).astype(float)

# Network: 2 inputs -> 16 hidden (ReLU) -> 3 outputs (softmax)
W1 = np.random.randn(2, 16) * 0.3
b1 = np.zeros((1, 16))
W2 = np.random.randn(16, 3) * 0.3
b2 = np.zeros((1, 3))

learning_rate = 0.1
epochs = 3000

for epoch in range(epochs):
    # Forward
    z1 = X_train @ W1 + b1
    a1 = relu(z1)
    z2 = a1 @ W2 + b2
    a2 = softmax(z2)

    # Cross-entropy loss. The 1e-8 is a numerical safety epsilon:
    # softmax outputs can be extremely small, and log(0) is -inf.
    loss = -np.mean(np.sum(y_train * np.log(a2 + 1e-8), axis=1))

    # Backward
    delta2 = (a2 - y_train) / len(y_train)
    dW2 = a1.T @ delta2
    db2 = np.sum(delta2, axis=0, keepdims=True)

    delta1 = (delta2 @ W2.T) * relu_derivative(z1)
    dW1 = X_train.T @ delta1
    db1 = np.sum(delta1, axis=0, keepdims=True)

    W1 -= learning_rate * dW1
    b1 -= learning_rate * db1
    W2 -= learning_rate * dW2
    b2 -= learning_rate * db2

    if epoch % 500 == 0:
        preds = np.argmax(a2, axis=1)
        targets = np.argmax(y_train, axis=1)
        acc = np.mean(preds == targets)
        print(f"Epoch {epoch:4d} | Loss: {loss:.4f} | Train Acc: {acc:.2%}")

# Test evaluation
z1_test = X_test @ W1 + b1
a1_test = relu(z1_test)
z2_test = a1_test @ W2 + b2
a2_test = softmax(z2_test)

test_preds = np.argmax(a2_test, axis=1)
test_targets = np.argmax(y_test, axis=1)
test_acc = np.mean(test_preds == test_targets)

print(f"\nTest Accuracy: {test_acc:.2%}")

labels = ["Normal", "Warning", "Critical"]
print("\nSample predictions (first 10 test samples):")
for i in range(10):
    pred_label = labels[test_preds[i]]
    true_label = labels[test_targets[i]]
    confidence = a2_test[i][test_preds[i]]
    status = "correct" if test_preds[i] == test_targets[i] else "WRONG"
    print(f"  Predicted: {pred_label:8s} ({confidence:.2%}) | "
          f"Actual: {true_label:8s} | {status}")
```

**Expected output (approximate):**

```text
Epoch    0 | Loss: 1.0157 | Train Acc: 47.50%
Epoch  500 | Loss: 0.0653 | Train Acc: 97.50%
Epoch 1000 | Loss: 0.0501 | Train Acc: 97.92%
Epoch 1500 | Loss: 0.0453 | Train Acc: 97.92%
Epoch 2000 | Loss: 0.0430 | Train Acc: 97.92%
Epoch 2500 | Loss: 0.0417 | Train Acc: 97.92%

Sample predictions (first 10 test samples):
  Predicted: Critical (100.00%) | Actual: Critical | correct
  Predicted: Critical (100.00%) | Actual: Critical | correct
```

```text
  input (2)       hidden (16)        output (3)

  temperature ──┬── h1              ┌─ normal
                ├── h2              │
                ├── h3  ────────────├─ warning
                ├── ...             │
                └── h16             └─ critical
  vibration ────┘
                    ReLU               softmax: the three
                                       probabilities add to 1
```

## Key takeaways

<CardGrid>
<Card title="A neuron" icon="star">
A weighted sum, a bias and an activation function. A network is many neurons arranged in layers.
</Card>
<Card title="Forward pass" icon="right-arrow">
In each layer: multiply by the weights, add the bias, apply the activation function. The output of one layer is the input of the next.
</Card>
<Card title="Backpropagation" icon="left-arrow">
The chain rule, applied from the output back to the input. It gives the gradient of the loss for every weight.
</Card>
<Card title="What frameworks do" icon="setting">
Libraries such as PyTorch and TensorFlow do what you coded here. They add automatic gradients, graphics processors for speed, and ready-made layers.
</Card>
<Card title="Regularizers you will meet next" icon="information">
Larger networks overfit, and two tools reduce it. **Dropout** sets a random part of the hidden values to zero at each training step, so the network cannot depend on any single neuron. **Batch normalization** rescales the values between layers, which makes training steadier.
</Card>
